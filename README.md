# SoftUI

A SwiftUI component library for soft, tactile interfaces inspired by neumorphism. SoftUI provides reusable controls, styles, shadows, and adaptive colors for macOS, iOS, and visionOS.

![SoftUI preview](Sources/SoftUI/Documentation.docc/Resources/soft.png)


## Installation

Add SoftUI to your Swift package dependencies:

```swift
.package(url: "https://github.com/Vaida12345/SoftUI.git", from: "1.0.0")
```

## Documentation

The full symbol documentation is available in the `Documentation.docc` catalog, including API details and SwiftUI previews.
